## Key Running

A simple math game where you answer questions by pressing the key that represents the answer to them. Try to avoid making too many mistakes in order to not be taken in by the dark cloud.

Made in Godot

Get the game here: https://mxinput.itch.io/key-running

Fonts used in game from: https://www.1001fonts.com/mister-licky-chops-font.html
